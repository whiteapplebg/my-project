# 🚀 财富管理与自动化模型 (Project v2.0)

本项目是将格雷厄姆《聪明的投资者》底层逻辑与 Python 自动化结合的实战工程。

## 🌟 核心模块
- **Wealth App**: 基于 NumPy 的复利模型，内置“安全边际”检测逻辑。
- **Auto Report**: 自动抓取系统运行环境并生成资产报告的脚本。

## 🛠️ 技术栈
- **环境隔离**: `venv` (已通过 .gitignore 净化)
- **核心依赖**: `numpy`, `os`, `platform`
- **版本控制**: 严格执行 Git 工作流
