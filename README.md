# 财富复利与安全边际评估工具

## 项目简介
本项目是一个用于财富复利模拟和投资安全边际评估的 Python 工具，结合了格雷厄姆投资理念。支持用户输入本金、年限、不同收益率，自动计算复利结果，并检测资产价格是否具备安全边际。

## 主要功能
- **复利计算**：输入本金和持有年限，自动对比不同投资收益率（3%、5%、10%）下的最终财富。
- **安全边际检测**：输入资产的内在价值和市场价格，判断是否达到格雷厄姆式安全边际（价格低于内在价值的 70%）。
- **输入校验**：防止非数字输入导致程序崩溃。

## 使用方法
1. 安装依赖：
   ```bash
   pip install numpy
   ```
2. 运行主程序：
   ```bash
   python wealth_app.py
   ```
3. 按提示输入本金、年限、内在价值和市场价格，查看复利模拟结果和安全边际评估。

## 主要逻辑说明
- `run_wealth_model()`：主入口，负责复利模拟和安全边际检测。
- `check_safety_margin()`：判断当前价格是否具备安全边际。
- `calculate_margin_of_safety()`：返回安全边际百分比。
- `main()`：独立安全边际评估工具（可单独调用）。
